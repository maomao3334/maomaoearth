# 绘制增强（v0.7.0）

## 改进内容

### 1. 3D 地形下可见
- 点：`CLAMP_TO_GROUND` 贴地，`disableDepthTestDistance=Infinity`，不会被地形遮挡。
- 线：`clampToGround: true` 贴地折线；被山体挡住时用半透明虚线 `depthFailMaterial` 提示。
- 面：贴地多边形 + 贴地轮廓线；填充半透明，不盖底图。
- 绘制预览同样贴地。

### 2. 顶点标签
- 点、线顶点、面顶点统一显示 `标记点 1 / 2 / 3...`。
- 标签白字 + 深色背景 + 描边，地形遮挡时仍可见。
- 「顶点标签」开关可一键隐藏/显示。
- 远距离（>3000 km）自动隐藏标签，避免满屏文字。

### 3. 实时量算
绘制线/面时 HUD 实时显示：
- 已添加顶点数；
- 光标经纬度；
- 线：累计长度（m/km）；
- 面：球面面积（m²/km²）。

### 4. 吸附
- 靠近已有顶点 14px 内自动吸附，线头/面角对齐；
- 地形拾取使用 `globe.pick`，贴地绘制。

### 5. 绘制要素列表
侧栏「要素列表…」：
- 名称、类型、长度/面积/坐标；
- 定位、改名、隐藏/显示、删除。

### 6. 导出/样式
- 新增导出 **KML / CSV**（保留 GeoJSON 导入导出）。
- 透明度滑杆；
- 「遮挡虚线」开关；
- 「顶点标签」开关；
- 线宽/颜色沿用原控件。

### 7. 双击快速标点
- 空闲时双击地图：立即创建 `标记点 N`，并打开编辑页；
- 双击已有标记：直接编辑；
- 绘制线/面时双击仍是“结束绘制”；
- 移除了 Cesium 默认双击缩放。

## 使用

- 侧栏「绘制与标注」→ 点/线/面；
- 双击结束线/面；
- 双击空白地图快速标点；
- 侧栏「要素列表…」管理；
- 导出 KML/CSV/GeoJSON。

## 验证

- 3 个要素（线/面/点）导入后：8 个顶点标签、8 个点、2 条线、1 个面。
- 实时量算示例：线 13.00 km，面 31.41 km²。
- 双击地图：创建 1 个标记点并打开编辑页。
- 无 page-error。
- 截图：`docs/screenshots/15-draw-enhanced.png`、`docs/screenshots/16-draw-list.png`。

## 限制

- 标签编号为全局递增，改名不改变编号。
- 贴地几何在极复杂地形/大量要素时开销高于普通折线；绘制少量要素无影响。
- 仅 WGS84 经纬度。
- 绘制要素暂不写入 `.leproj`（坐标标点会写入）。
