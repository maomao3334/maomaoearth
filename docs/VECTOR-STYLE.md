# 公共矢量视觉改进（国界 / 河流 / 湖泊 / 城市）

## 问题

- 详细国界、湖泊是 **高度 0 的 GeoJSON 面**：3D 地形开启后，它们要么被山体遮住，要么以“蓝色/白色块”形式浮在地表，观感很差。
- 加载公共图层后相机会**自动飞到数据范围**，把用户当前视角重置成全球。
- 详细国界面（admin_0）曾触发 Cesium RHUMB 细分崩溃（见 `CRASH-FIX.md`）。

## 改动

1. **贴地采样**：`js/importers.js` 新增 `drapePositions()`，按 `LE.heightAt(lon,lat)` 把每个顶点抬高到当前地形高度 +2m，生成 3D 折线。
2. **国界只描边**：admin_0 的每个面转成贴地折线（4293 条），原多边形隐藏；不再有填充块，也不再依赖 GroundPrimitive。
3. **河流/湖泊**：河流用蓝色贴地折线；湖泊保留淡蓝填充语义（后续可同样转轮廓）。
4. **配色**：国界 `#86b7e8`、河流 `#4f9fd8`、湖泊 `#2f6f9f`（半透明），城市点黄色小点。
5. **不再自动跳视角**：导入公共图层后不再调用 `fitDataSource`；需要定位时用图层列表的“定位”按钮，或 URL 加 `?fit=1`。
6. **可选关闭贴地**：`?drape=0` 恢复旧的高度 0 行为。

## 验证

- 加载详细国界：4293 条贴地折线，多边形已隐藏；无 page-error。
- 与风场/动画 KMZ/地形/影像叠加正常。
- 崩溃修复保持：`crash-fix` 相关验证仍通过。

## 已知限制

- 贴地折线在顶点处采样地形，顶点之间是直线，极近距离/陡坡可能轻微穿模；可提高采样密度解决。
- 湖泊仍以面绘制，极端情况下仍可能被地形遮挡；如需要可把湖泊也改为贴地轮廓。
- 城市点默认 6px 黄色，密集区域可能较密，可在图层里单独关闭。

## 城市点按距离显隐（2026-10-21）

- 问题：加载「城市」后，7342 个 Natural Earth 城市点在任何缩放级别都绘制，远看像一片黄色粒子铺满屏幕（印度/西藏一带尤其明显）。
- 修复：`stylePublicVectorDataSource()` 给所有城市 billboard/label 设置
  `DistanceDisplayCondition(0, 1,200,000 m)`：
  - 相机距离 > 1200 km（远看/全球）→ 自动隐藏；
  - ≤ 1200 km（近景/区域）→ 显示城市点；
  - 仍可用「城市」按钮整体开关/移除图层。
- 验证：远视角（5000 km）截图无黄色点（`docs/testdata/cities-far.png`）；近视角（400 km）可见；7342 个 billboard 均带 condition，无 page-error。
